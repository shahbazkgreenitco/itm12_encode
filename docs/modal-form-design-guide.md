# Modal Form Design Guide

This guide documents the reusable field design currently used in:

- `resources/views/users/add-modal.blade.php`

Use this when building a new modal that should match the same input design.

## Goal

Keep the same visual design by reusing the same class structure.

When adding a new field, only change:

- `for`
- `id`
- `name`
- label text
- `placeholder`
- input `type`
- SVG icon

Do not add inline CSS for spacing, label width, or the required `*`.

## Root Setup

Wrap the modal form or modal body with:

```html
class="amg-form-theme"
```

This class activates the shared field styling.

## Shared CSS

Move this CSS to your global stylesheet if multiple modals will use the same design:

```css
.amg-form-theme .amg-form-section-title {
    min-height: 36px;
}

.amg-form-theme .amg-form-error {
    color: red;
}

.amg-form-theme .amg-form-field {
    display: flex;
    align-items: center;
}

.amg-form-theme .amg-form-field > .form-label,
.amg-form-theme .amg-form-field > .input-group > .form-label {
    min-width: 130px;
    margin-right: 0.5rem;
    margin-bottom: 0;
    flex-shrink: 0;
}

.amg-form-theme .amg-form-field > .input-group {
    flex: 1 1 auto;
}

.amg-form-theme .amg-form-footer {
    padding-inline: 40px;
}

.amg-form-theme .amg-form-hidden {
    display: none;
}

.amg-form-theme .form-label.required::after {
    content: "*";
    color: #dc3545;
    margin-left: 0.25rem;
}

@media (max-width: 767.98px) {
    .amg-form-theme .amg-form-field {
        flex-direction: column;
        align-items: stretch;
    }

    .amg-form-theme .amg-form-field > .form-label,
    .amg-form-theme .amg-form-field > .input-group > .form-label {
        min-width: 100%;
        margin-right: 0;
        margin-bottom: 0.5rem;
        text-align: left !important;
    }
}
```

## Main Classes

| Class | Purpose |
| --- | --- |
| `amg-form-theme` | Root wrapper for the reusable modal form styling |
| `amg-form-field` | Main field layout wrapper |
| `form-label b1-text me-2 mb-0 text-end` | Standard field label |
| `required` | Add to label when the field needs the red `*` |
| `input-group` | Input and icon wrapper |
| `input-group-text` | Icon container |
| `form-control` | Text input or textarea styling |
| `form-select` | Select styling |
| `textarea` | Extra textarea class already used in this modal |
| `amg-form-section-title` | Section header styling |
| `amg-form-error` | Red validation/error message block |
| `amg-form-hidden` | Hide a block without inline CSS |
| `amg-form-footer` | Footer button spacing |

## Standard Field Structure

Use this exact structure for a normal text field:

```html
<div class="col-md-6">
    <div class="amg-form-field d-flex align-items-center">
        <label for="employee_code" class="form-label b1-text me-2 mb-0 text-end required">
            Employee Code
        </label>
        <div class="input-group">
            <span class="input-group-text">
                <!-- svg icon -->
            </span>
            <input
                name="employee_code"
                id="employee_code"
                type="text"
                autocomplete="off"
                class="form-control"
                placeholder="Enter Employee Code" />
        </div>
    </div>
</div>
```

## Select Field Structure

```html
<div class="col-md-6">
    <div class="amg-form-field d-flex align-items-center">
        <label for="department_id" class="form-label b1-text me-2 mb-0 text-end required">
            Department
        </label>
        <div class="input-group">
            <span class="input-group-text">
                <!-- svg icon -->
            </span>
            <select name="department_id" id="department_id" class="form-select">
                <option selected disabled>Select Department</option>
            </select>
        </div>
    </div>
</div>
```

## Textarea Field Structure

```html
<div class="col-md-6">
    <div class="amg-form-field d-flex align-items-center">
        <label for="remarks" class="form-label b1-text me-2 mb-0 text-end">
            Remarks
        </label>
        <div class="input-group">
            <span class="input-group-text">
                <!-- svg icon -->
            </span>
            <textarea
                name="remarks"
                id="remarks"
                class="form-control textarea"
                placeholder="Enter Remarks"></textarea>
        </div>
    </div>
</div>
```

## Required Fields

Do this:

```html
<label for="first_name" class="form-label b1-text me-2 mb-0 text-end required">
    First Name
</label>
```

Do not do this:

```html
<label>First Name <span class="required">*</span></label>
```

The red `*` is already generated by CSS.

## Section Title Pattern

Use this for section headers inside the modal:

```html
<div class="amg-form-section-title d-flex align-items-center justify-content-center justify-content-md-start text-center text-md-start mb-2">
    <span class="fs-11 fs-md-5">Create Account (Required)</span>
</div>
```

## Error Message Block

```html
<div id="fillthedata" class="amg-form-error"></div>
```

## Hidden Block Without Inline CSS

```html
<div class="col-md-6 amg-form-hidden" id="technicianCompanyAccess">
    ...
</div>
```

## Footer Pattern

```html
<div class="amg-form-footer modal-footer d-flex justify-content-start mb-4 pb-4 py-0">
    ...
</div>
```

## Layout Rules

- Use `col-md-6` for two fields per row.
- Use `col-md-12` if a field should take full width.
- Keep the order: `label` -> `input-group` -> `input/select/textarea`.
- Keep `amg-form-field` on the direct wrapper around the label and input group.
- Keep `amg-form-theme` on the parent container or the layout rules will not apply.
- Use `required` only on the label when the field is mandatory.

## Developer Checklist

- Add the root class: `amg-form-theme`
- Use `amg-form-field` for each field row
- Use `form-control` for inputs and textareas
- Use `form-select` for selects
- Use `required` on the label if the field is mandatory
- Do not use inline styles
- Do not manually type the `*`
